# Style Guide

## Brand
- **Name:** Brain Byte
- **Niche:** Science & tech explainers
- **Tone:** Playful, meme-y, curious — never condescending. We're the smart friend
  who gets excited about weird facts, not a textbook.

## Voice (writing)
- Short sentences. Talk *to* the viewer, not *at* them ("you know that feeling when...").
- Lead with the surprising part, explain the mechanism second.
- Humor via unexpected comparisons/analogies, not forced jokes.
- Avoid jargon; if a technical term is necessary, define it in the same breath.

## Visual
- Palette: see `src/themes/colors.ts` (placeholder — update with real brand colors).
- Format: vertical 1080x1920, 30fps, <60s.
- Motion: punchy/snappy easing, not slow fades — short-form viewers scroll fast.
- Typography: large, high-contrast text for mobile/muted viewing.

## Recurring formats
1. **"Wait, how does X actually work?"** — single-concept explainer.
2. **"The X that shouldn't work"** — counterintuitive tech/science facts.
3. **"Number of the day"** — one striking stat, visualized.
